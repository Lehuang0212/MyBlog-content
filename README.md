# 🚀 欢迎来到 LH 的个人博客

本博客基于 **GitOps** 理念与**极简主义**构建的全栈极客博客。

## ⚙️ 核心驱动架构

* **前端展示**：Next.js + Tailwind CSS，打造沉浸式 IDE 禅模式交互。
* **数据流向**：Prisma ORM + SQLite 驱动的轻量级关系型结构。
* **内容管理**：Obsidian 本地编辑 $\rightarrow$ GitHub 弹药库 $\rightarrow$ 自动化同步脚本 `(Sync Script)`。
* **智能核心**：深度接入 **DeepSeek 大模型**，提供全动态的 AI 文章摘要与剖析。

> "Talk is cheap. Show me the code." —— Linus Torvalds

## 🧭 探索指南

1.  你可以点击左侧的工作区（`Workspace`）图标，浏览我的技术笔记。
2.  按下键盘上的 <kbd>Ctrl</kbd> + <kbd>K</kbd>，可以唤起**全局闪电检索**，瞬间定位你需要的文章。
3.  点击任何一篇文章顶部的 **Generate** 按钮，唤醒 DeepSeek 对文字进行摘要总结。
4.  随时点击左上角的 **LH 头像**，回到这个欢迎页面。

Enjoy reading, and keep coding.
